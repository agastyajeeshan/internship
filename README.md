
# Week 1 Internship Task

## Transforming Wireframes into Static Web Pages

### Project Overview
A responsive static landing page developed using HTML5 and CSS3 as part of the Week 1 internship assignment.

### Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Media Queries

### Features
- Semantic HTML structure
- Responsive navigation and layout
- Hero section
- Services section
- About section
- Contact section
- Footer
- Responsive desktop, tablet and mobile layouts

### How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

### Project Structure
- index.html
- style.css
- README.md

### Learning Outcomes
Practiced semantic HTML, CSS styling, responsive layouts, Flexbox, Grid and media queries.
